Excel reader fixtures from ExcelDataReader v3.9.0, commit f3343f5524518923bdeb4801e5003c0417fd35f3, src/TestData. Distributed under the accompanying MIT licence. Password fixtures use the public test password `password`; they contain no credentials. All fixtures are public upstream test data, not StatsDirect user data. The compatibility tests compare known cells, types and whole-sheet data across the corresponding formats.

`structural-pivot-slicer.xlsx` is a StatsDirect regression fixture created in Microsoft Excel 16.113.3 on 9 October 2026. It contains four fictional observations (groups A/B, counts 10/20/30/40), a native pivot report, a Group slicer, a merged heading and a three-dimensional formula. It contains no participant data or external connections. `Tests/test_excel_structures.py` uses it to verify report/source movement and preservation of cache and slicer identities. Other structural fixtures are generated deterministically by that test.

`structural-comments.xlsx` was created in the same Excel version with a fictional worksheet and a local QA comment on A2. It includes the native threaded-comment/legacy-fallback relationship set; the test moves both together and checks stable text and thread/person IDs.
