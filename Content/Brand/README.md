# StatsDirect symbol

`statsdirect.png` is the original 256 × 256 PNG frame extracted without modification from `StatsDirectUI/Graphics/sd3.ico` in the Windows core repository, commit dcc2af8f0ec55d736a98acac029297510195e2df (5.0.8).

The application ICNS is generated from this supplied symbol by `Scripts/build-icon.py`. This artwork remains covered by the StatsDirect licence; it is not a new or AI-generated logo.
