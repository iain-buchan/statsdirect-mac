Analysis

 

Follow the instructions above the worksheet when choosing data for an analysis. On Windows, click or hover over Data info to review the data already supplied to the analysis. For a further analysis, use the displayed controls to choose the variables and options for that analysis.

Available under the Analysis menu section at all times:

  • EXACT TESTS ON COUNTS
  • CHI-SQUARE TESTS
  • PROPORTIONS
  • RATES
  • SAMPLE SIZE
  • DISTRIBUTIONS
  • RANDOMIZATION
  • CLINICAL EPIDEMIOLOGY

 

Also available under the Analysis menu section when a workbook is active:

  • DESCRIPTIVE STATISTICS
  • PARAMETRIC METHODS
  • NONPARAMETRIC METHODS
  • ANALYSIS OF VARIANCE
  • REGRESSION AND CORRELATION
  • AGREEMENT ANALYSIS
  • SURVIVAL ANALYSIS
  • META-ANALYSIS
  • CROSSTABS
  • FREQUENCIES
  • GRAPHICS

 

At the bottom of the Analysis menu, Calculator has its own section immediately before Options. Calculator is available with any document active.
