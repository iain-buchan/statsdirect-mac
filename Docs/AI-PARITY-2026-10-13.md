# Mac AI parity — 13 October 2026

Ports the relevant behaviour from Windows commit
`95fbc97d5a497d6c8469e9b9309c0dcdac943cb9` onto the existing Mac work.
The calculation engine remains 5.1.0 at its existing pin. No Windows or shared
report-editor sources were modified.

## Changes

- Protocol diagnostics use fixed event/tool names. Unknown names, raw responses,
  error text, account values and conversation text are excluded. Learning records
  retain a fixed failure category rather than an exception message. Mac did not
  create the legacy raw diagnostic files removed by the Windows correction.
- Learning streaming preserves message-relative selection endpoints (including
  backwards and mixed-format selections) and the reading position. Selection
  pauses automatic following; clearing it at the bottom resumes following.
  Script AI retains its native NSTextView, with stable identities for streamed
  R-block links so completion does not insert links ahead of selected text.
- A failed Learning renderer is replaced on reopening. Native portfolio state
  and the latest partial/completed reply are replayed without sending the question
  again. Old handlers are detached, the restricted configuration is reapplied,
  and stale callbacks are rejected. Closing a failed tab retains received text.
- Script AI has a bottom **Open R code** control and per-block **Open in R** links.
  Both build a reviewable script from the full approved local source snapshots,
  literal worksheet values actually read, and preceding R blocks through the
  selected message/block. Editing a source later does not change the export.
  New conversations start without prior context; generation tokens reject old
  code clicks after switching conversations. Opening never runs code.
- Learning's per-block action uses the same replay builder, scoped to its lesson.
  Local replay metadata survives portfolio reopening, but is excluded from AI
  conversation text and learner-record exports. Worksheet tools supply explicit
  `.statsdirect_data[[datasetId]][['column_N']]` bindings instead of assuming
  headings are R variables. Missing rows and quoted text are retained.
- Previously requested lesson refinements and removal of the pending-review
  notice remain included; see `Learn/CONTENT-REFINEMENTS-2026-10-12.md`.
