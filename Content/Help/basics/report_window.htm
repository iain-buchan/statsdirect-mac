Report window

 

Menu location: File > New Report; a report also opens by itself when an analysis runs with none open, and File > Open opens a saved report.

 

A report is one editable document. Each result of an analysis is an item in it: the heading, the tables and the charts of one run, kept with a record of the run (the workbook, sheet, columns and rows of each input, the settings and the main results), from which Continue in R writes its script and Help finds the method's topic. Type anywhere, select across results and format with the toolbar; text typed after the last result belongs to it. Reports are set in Arial, with the standard colours of StatsDirect's results: blue for confidence intervals, green for P values, red for warnings.

 

The toolbar holds Save, Undo and Redo, Cut, Copy and Paste, Find, the formatting (bold, italic and underline, the alignment, the font size, and Clear formatting for the paragraph at the cursor or the blocks selected), Add text for a section of your own, Help for the result the cursor is in, AI assistance, which opens the Script AI pane for that result, and the R button, which continues that result, or the latest when the cursor is in none, in the R script window. In a narrow window the formatting moves behind More.

 

Click the first heading of a result to select the whole result, and Shift-click another heading to select a run of results; Ctrl+A selects them all. Delete or Backspace removes what is selected, results among it, and Undo brings it back. Drag a selection to move it; hold Ctrl while you drag to copy it. The right-click menu offers Cut, Copy, Paste, Select result, Select all and Help for the result under the pointer, with Continue in R and Open data and settings in R for a result, and Save chart as SVG and Save chart as PNG on a chart.

 

A chart is a vector picture drawn into the report. Click it to select it: Left, Centre and Right on the toolbar align it, the handle at its free corner resizes it, and the arrow keys adjust its size, in larger steps with Shift. Save chart as SVG saves the chart itself, which drawing programs and browsers open and scale without loss; Save chart as PNG draws it at twice its size on the page, for programs that take only pictures.

 

Paste accepts clipboard SVG, PNG and bitmap pictures as well as formatted text. Choose Add text for a new section, place the cursor in it and paste with Ctrl+V or the toolbar. SVG remains vector artwork; PNG and bitmap pictures are embedded as PNG. The saved HTML report includes the picture, so it does not depend on the original file. In StatsDirect 5.2.3, press Enter with a picture selected, or with the cursor immediately after it, to create a normal paragraph below it in the same result. You can then keep typing without adding a separate text section. Undo and Redo include both picture pastes and the new paragraph. To bring a chart from R output, right-click the chart and choose Copy image, then paste here.

 

Copy puts the selection on the clipboard as formatted text with its pictures. Word pastes it with the report's fonts, tables and charts, and Excel takes the tables as cells and the charts as pictures.

 

Save keeps the report as an editable HTML file, as Save As does by default, which a web browser shows and StatsDirect reopens with its results, their records and their help intact. File > Open opens one, and a plain text file opens as a new report. Save As also offers a Word document or a PDF; either writes a copy and leaves the HTML report as it is. Print and Print Preview print the report through the browser's print dialog. A report in the earlier RTF format opens as a new report, its charts converted; MHTML and DOCX reports are not opened: open them in Word, save them as HTML, and open that file. The status line at the bottom shows Unsaved changes and the file last saved, and closing a changed report asks whether to save it, in the banner at the top of the window.

 

File > Export Jupyter notebook writes a self-contained .ipynb file to share with a statistician or data science colleague. It includes the edited report with its tables and pictures, the recorded input data and settings, and the available R code for each analysis. The original report is kept separately from the R cells, which have not been run during export. Open the notebook in a Jupyter-compatible editor with an R kernel to run or adapt the code. If an original input was not saved with the result, open its unchanged workbook before exporting; changed or missing data must be restored, or the analysis rerun. Manually written and imported sections keep their report content, with a note when data or an R recipe are unavailable. Exporting leaves the editable HTML report and its unsaved changes intact.

 

File > Open also opens a StatsDirect-exported R notebook (.ipynb). The current notebook report cells, notes and supported saved R outputs open as an editable report; its current R code opens in a script tab, and its embedded input data open in new worksheets. Code runs only when you choose Run. These are new, unsaved documents: save the report as HTML, the script as R and the data as an Excel workbook. The original notebook is unchanged. This initial support is for StatsDirect notebooks; general notebooks and other kernels require a Jupyter-compatible editor.

 

Find (Ctrl+F) opens a find bar under the toolbar and shows the text found selected. Help on the toolbar, F1 and Help on the right-click menu open the topic of the result the cursor is in.
