# Course packs for StatsDirect Learning

In **Help → Learning Options → Import course pack**, a tutor can provide one or more UTF-8 Markdown/text files, searchable PDFs, or the JSON template alongside this document. A JSON pack groups documents under one course title. Replace the template's illustrative content with your own learning outcomes, notes, terminology, worked examples and formative marking guidance. Include module/version details in titles or text. Word and PowerPoint material can be exported as PDF first; scanned pages need OCR before import.

The app keeps the material locally. On each explicit **Send**, a local keyword search selects up to five overlapping excerpts (at most 1,700 characters each) using the latest question and lesson topic. OpenAI receives those excerpts with the conversation and learning goals. The prompt asks for document/page references, acknowledges gaps and keeps course text below the application's instructions. It does not fine-tune model weights, upload a vector store, run course code or automatically add scored questions. A handout that is not retrieved cannot influence that reply. Review the references and verify important explanations.

A pack can contain up to 1 MB of extracted text and 500 documents/pages; source files are limited to 16 MB each. Import is atomic: invalid input leaves the active pack unchanged. Replacing a pack archives the previous local version. The JSON schema has `schemaVersion: 1`, a `title`, and `documents` containing unique `id`, `title` and `text` strings. Source filenames and PDF page numbers appear in citations. Credentials and learner identity fields are not part of a pack.

The conversation export records the sources used for each AI reply. Original files are not automatically attached to review emails. The recipient remains responsible for any independent marking, accreditation and CPD decisions. Only share course material you are authorised to send to the chosen API account.
